# Architecture Decision Records (ADR)

## Introducción

Este directorio contiene las decisiones arquitectónicas importantes tomadas durante el desarrollo de Khipu.

Cada ADR documenta:

- El contexto del problema.
- Las alternativas evaluadas.
- La decisión tomada.
- Las consecuencias de dicha decisión.
