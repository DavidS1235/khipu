# ADR-004: Uso de Flutter para aplicación móvil

## Estado

Aceptada.

## Contexto

Khipu requiere una aplicación móvil inicialmente orientada a usuarios peruanos.

Se busca:

- Desarrollo multiplataforma.
- Velocidad de desarrollo.
- Experiencia consistente.

---

## Alternativas consideradas

### Desarrollo nativo Android/iOS

Ventajas:

- Máximo rendimiento.
- Acceso completo a capacidades del sistema.

Desventajas:

- Mayor tiempo de desarrollo.
- Dos bases de código.

---

### Flutter

Ventajas:

- Una sola base de código.
- Desarrollo rápido.
- Buen rendimiento.
- Amplio ecosistema.

---

## Decisión

Se utilizará Flutter para la aplicación móvil de Khipu.

---

## Consecuencias

### Positivas

- Menor tiempo de desarrollo.
- Código compartido entre plataformas.

### Negativas

- Dependencia del ecosistema Flutter.
